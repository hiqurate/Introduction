# Cyber Assessment V2

Hiqurates security framework assessment platform (V2).

## Features

- Pre-assessment org setup (name, industry, requirements)
- Formal vector PDF reports (jsPDF)
- Hiqurates AI-enhanced findings and remediation
- Streamlined on-screen report UI

## AI configuration

Credentials are in `js/ai-config.js` (committed for GitHub Pages testing). For production, prefer keeping keys out of the public repo and loading them at deploy time.

## Run locally

Open `index.html` in a browser or serve the folder with any static file server.
